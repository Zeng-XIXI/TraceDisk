# TraceDisk 项目结构说明

当前项目约有：

- 项目文件：116 个
- `target/` 编译缓存：约 3.2 GB、9,977 个文件（日常最值得清理的是 `target/`、`node_modules/`、`dist/` 和 `.DS_Store`；不要删除 Rust/React 源码、配置、锁定文件、图标和发布脚本。）
- `node_modules/` 前端依赖：约 88 MB、1,168 个文件
- `dist/` 前端构建结果：约 252 KB
- 当前可双击的 `TraceDisk.app`：约 11 MB

注意：本次已移除的 `auth.rs` 和 `docs/AUTHENTICATION.md` 在 Git 状态中显示为删除，提交后会彻底从项目版本中消失。

| 目录/文件                            | 作用                             | 建议                             |

推荐使用安全的官方清理方式：

```
cd /Users/allen/code/TraceDisk
cargo clean
```

这会清空整个 `target/`。运行前先把 [TraceDisk.app](/Users/allen/code/TraceDisk/target/release/bundle/macos/TraceDisk.app) 复制出去，否则它也会被删除。

## 未来可能出现但当前没有的忽略目录

`.gitignore` 还规定了这些内容不进入 Git：

| 名称                 | 作用                               | 建议                                 |
| -------------------- | ---------------------------------- | ------------------------------------ |
| `release/`           | 正式 DMG、ZIP、EXE 发布产物        | ⚠️ 可删除，但它可能是你准备发布的文件 |
| `recovered/`         | 恢复出来的视频文件                 | ❌ 不要当作缓存清理，可能是用户数据   |
| `*.img`、`*.raw`     | SD 卡镜像或原始磁盘副本            | ❌ 不要随意删除，可能是恢复源数据     |
| `.idea/`、`.vscode/` | JetBrains / VS Code 本地编辑器设置 | ✅ 可删，不影响项目功能               |

最简清理建议：

- 想释放大量空间：清理 `target/`。
- 想重新安装前端依赖：清理 `node_modules/`。
- 想清理前端产物：清理 `dist/`。
- 想清理 macOS 杂项：删除所有 `.DS_Store`。
- 不要清理 `recovered/`、`.img`、`.raw`，它们可能是恢复成果或恢复源。
