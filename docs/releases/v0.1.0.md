# TraceDisk v0.1.0

TraceDisk 的首个 macOS 公开预览版本，面向误删 DJI 相机视频的 exFAT SD 卡恢复。

## 下载选择

- `TraceDisk-v0.1.0-macos-arm64.dmg`：Apple Silicon Mac 推荐下载。
- `TraceDisk-v0.1.0-macos-arm64.zip`：ZIP 格式的同一应用。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

系统要求：Apple Silicon Mac，macOS 12 或更高版本。当前版本不支持 Intel Mac 和 Windows。

## 主要功能

- 直接只读扫描 SD 卡，不要求先创建整卡镜像。
- 快速读取 exFAT 删除目录项、FAT 和分配位图。
- 连续存储或 FAT 链完整的文件可以立即恢复。
- 按 FAT 链顺序拼接非连续视频片段。
- 支持选择多个候选文件批量恢复，并预检目标磁盘容量。
- 快速扫描无结果时，可逐块深度扫描整张卡并显示进度。
- 扫描及恢复前验证外置设备，拒绝读取内置磁盘。
- 恢复结果只能写入其他磁盘，且不会覆盖已有文件。

## 安装和首次打开

这个预览版本采用临时签名，尚未使用 Apple Developer ID 公证。下载后如果 macOS 阻止打开：

1. 将 `TraceDisk.app` 拖入“应用程序”。
2. 在 Finder 中按住 Control 点击应用，选择“打开”。
3. 如果仍被阻止，进入“系统设置 → 隐私与安全性”，在安全提示处选择“仍要打开”。
4. 在“系统设置 → 隐私与安全性 → 完全磁盘访问权限”中添加并启用 TraceDisk。
5. 使用 `Command + Q` 完全退出应用，重新打开后再连接 SD 卡。

## 使用提醒

- 发现误删后立即停止使用 SD 卡，不要继续拍摄、格式化或修复磁盘。
- 恢复结果必须保存到其他磁盘，不能写回原 SD 卡。
- 快速扫描期间 SD 卡会从 Finder 暂时消失，这是安全卸载，不是推出；重新插拔即可再次挂载。
- FAT 链完整只表示片段顺序可确定，不保证视频数据没有被新内容覆盖。

## 当前限制

- 快速删除目录扫描目前主要支持 exFAT；FAT32 需要使用深度扫描。
- 深度扫描主要识别物理连续的 MP4/MOV 容器，尚不能可靠重组 FAT 链完全丢失的任意碎片视频。
- 该版本未经 Apple 公证，适合作为技术预览版分发。
